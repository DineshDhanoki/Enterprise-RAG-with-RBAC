# Security policy

## Current scope

The current repository is a static frontend prototype. It does not process real credentials, private documents, production identity tokens, or live model requests. Do not use the demo with sensitive data.

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Contact the repository maintainer privately through the contact options on [@DineshDhanoki](https://github.com/DineshDhanoki), including:

- a concise description of the issue;
- affected files or URLs;
- reproducible steps or a minimal proof of concept;
- the potential impact.

Allow reasonable time for acknowledgement and remediation before public disclosure. Please do not include secrets or personal data in the report.

## Security direction

The production roadmap treats deny-by-default authorization, pre-retrieval filtering, provenance, redaction, and auditable access decisions as release-blocking requirements—not optional polish.
